# English Dictation Trainer

Открой `index.html` в браузере.

## Как добавить свои слова

Открой `script.js` и найди:

const units = {
  1: [
    { ru: "имя", en: "name", type: "noun" }
  ]
};

Добавляй свои слова по такому же принципу.

Типы:
- noun — существительное, розовая карточка
- verb — глагол, голубая карточка
- adjective — прилагательное, жёлтая карточка
- phrase — фраза, белая карточка
- other — другое, зелёная карточка

Например:
{ ru: "путешествовать", en: "travel", type: "verb" }

Логика:
1. Выбираешь Unit.
2. Нажимаешь «Начать».
3. Видишь русское слово на цветной карточке.
4. Пишешь английское слово.
5. Если правильно — карточка плавно переворачивается.
6. Через короткую паузу появляется следующее слово.
7. В конце показывается результат.
